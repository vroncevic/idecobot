# Contributing to idecobot

The following is a set of guidelines for contributing to **idecobot** and its package, which are hosted in the [idecobot](https://github.com/vroncevic/idecobot) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

**idecobot** project and everyone participating in it is governed by the [idecobot code of conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [idecobot](mailto:elektron.ronca@gmail.com).
